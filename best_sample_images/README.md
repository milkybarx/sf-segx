# Best Sample Images Showcase

This directory contains curated solar observation images demonstrating both high-precision segmentation results and CME Earth-impact scenario simulations for the Solar Filament Intelligence dashboard.

## 🖼 Showcase Roster

### 1. `01_best_segmentation_sun2.jpg` (Best Model Segmentation Benchmark)
- **Primary Feature**: Highest overall segmentation accuracy and confidence (**0.946**).
- **Detections**: 17 filaments extracted with clean boundaries, precise cyan spines, and yellow contour outlines.
- **Primary Filament**: Area = $2,934.5\text{ px}^2$, Skeleton Length = $322\text{ px}$.

### 2. `02_high_contrast_sun4.jpg` (High-Contrast Multi-Filament Benchmark)
- **Primary Feature**: Sharp limb and active-region filament structures (**0.928** confidence).
- **Detections**: 8 distinct filaments.
- **Primary Filament**: Area = $1,091.0\text{ px}^2$, Skeleton Length = $130\text{ px}$.

### 3. `03_earth_direct_hit_cme.jpg` (Earth Direct Hit CME Simulation)
- **Primary Feature**: Disk-center eruption vector pointing directly at Earth (**$6.3^\circ$ angular separation**).
- **Simulation Result**: 
  - Triggers **`CRITICAL WARNING: Eruption vector intersects Earth's future orbital position within 25°`**.
  - Marks satellite assets (SOHO, SDO, GOES-16, GOES-18, ISS, GPS) as **`DIRECT HIT`** on the polar chart.

### 4. `04_earth_cme_storm_warning.jpg` (Geomagnetic Storm Warning CME Simulation)
- **Primary Feature**: Active-region filament eruption within the Earth CME cone (**$12.8^\circ$ angular separation**).
- **Simulation Result**: Triggers **Geomagnetic Storm Warning** and interactive 3D Parker Spiral propagation.
